# Project BOQ

面向SketchUp的本地工程算量与报价插件。公开仓库用于使用说明、版本更新与发行信息；核心源码不在此仓库公开。

## 功能

- 正式、待确认、草稿、历史、参考及可选范围管理。
- 单面表面积、选中边长度、组及组件实例数量。
- 整面、工装区域、拆改面积三类选择与分类汇总。
- 清单、单价、人工审核、项目JSON保存与加载。
- Excel可打开的CSV，以及可打印HTML报价。

## 安装使用

取得发行RBZ后，在SketchUp扩展程序管理器选择“安装扩展程序”，重启后从扩展程序菜单打开Project BOQ。使用前保存模型和项目数据。内部测试环境为Windows SketchUp 2024，其他版本未验证。

默认勾选整面面积，扫描未隐藏、图层可见的面；工装与拆改需手动标记后选择计入。各类别可能重叠，叠加量不是建筑净面积。不同工序单价不同，应分别建立清单。

本工具尚不支持CAD解析、自动识别施工区域、完整项目漏项判断和原XLS/XLSX排版复刻。
