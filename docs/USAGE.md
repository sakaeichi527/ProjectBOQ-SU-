# Project BOQ 0.2.0：整面 / 工装 / 拆改面积

## 安装更新

先保存当前SU模型与插件项目JSON。在SketchUp“扩展程序管理器 → 安装扩展程序”中选择`ProjectBOQ_0.2.0.rbz`，重启SketchUp，再从扩展程序菜单打开Project BOQ。已有项目JSON可加载，加载后仍需重新审核清单。

插件为未签名内部测试包，Windows SketchUp 2024为本轮功能测试环境。无需安装Python或独立EXE。只保存外部项目数据，不修改模型几何。

## 默认：计算所有整面面积

1. 打开插件后，“整面面积”选项卡默认激活，“计入全部整面面积”默认勾选。
2. 不需要先选择模型对象，点击“计算勾选面积（全模型可见面）”。
3. 插件递归扫描全模型，按当前隐藏和图层状态计算；显示扫描面数，可取消。取消后不会使用半成品结果。
4. 结果显示整面面积、面数，以及勾选类别的叠加汇总，汇总自动填入清单工程量。

“可见面”按你确认的口径，指未隐藏且图层可见的面，包含转动视角后能看到的面。不按当前镜头遮挡、屏幕范围或朝向裁剪；不是屏幕像素面积。隐藏的父组会排除其全部子面，关闭图层/图层文件夹的面不参与。pending和正式施工均参与；已标记草稿、历史、参考、可选范围仍不计入。

整面按现有模型的单面实际几何面积计算，孔洞随模型边界扣除；曲面按构成面的面积累加。组的各侧面、底面以及未隐藏的内部面也会计入，不自动辨认它们是否属于施工面；重叠实例按实例分别计算。它不是建筑面积或自动识别后的墙地顶净面积。

## 工装区域选项卡

1. 在SU中选择施工饰面区域的面、组或组件，必要时进入组内选面。
2. 点击“工装区域”选项卡，再点击“把当前选区标记为此类区域”。标记不修改SU几何。
3. 勾选“叠加工装区域面积”，重新计算。
4. 需要排除局部时，选中子面，点击“从此类区域排除当前选区”。子级标记优先于父级。

工装区域需要人工指认；不自动根据效果图或材质推断。如果区域只占一个完整面的局部，先在模型副本中划分对应面，或用“手工补量”并记录依据。不要把整面随意标成局部区域。

## 拆改面积选项卡

同样先选择模型中表达拆除/改造范围的面或组，点击“拆改面积”选项卡并标记，再勾选“叠加拆改面积”。已拆除但当前模型不存在的原始构件，不能凭空恢复面积；请依据拆改图手工补量。

三个类别可以独立勾选：仅整面、仅工装、仅拆改，或任意组合。切换选项卡不等于勾选计入；勾选后需点击计算按钮。全不选会提示至少选择一类。

## 面积叠加的含义

例如整面100㎡，其中工装20㎡、拆改10㎡：只选整面结果100㎡；三类全选的叠加工序量130㎡。整面不会自动扣掉工装/拆改区域。因此130㎡不是去重后的建筑净面积，也不代表三类应采用同一单价。

若三类单价不同，建议分别勾选、分别计算、分别建立清单行：例如整面基层100㎡、工装饰面20㎡、拆改10㎡。这样各行单价及金额有明确依据。不要把130㎡统一套一个单价，除非合同确实采用这种计价口径。

## 保存、审核、导出

填写项目名、费用率后点击“应用设置”。取量后填写清单名称、单价、工艺及客户说明，加入清单并逐行审核；“保存项目”将范围标记、区域标记、类别选择和清单一起保存到`.boq.json`。该文件包含内部成本，请内部保管。

导出前重新核验模型与区域标记；变化后需重新计算并替换旧行。清单仍需审核，即使取量包括pending对象。退出SketchUp前务必保存项目JSON。

CSV可用Excel打开，含UTF-8 BOM，不保留原XLS排版。HTML为分类报价，可在浏览器打印为PDF。客户导出不包含内部成本字段，但你填写到公开说明中的任何成本文字仍会公开。

原有选区单面面积、边长、组/组件个数和范围标记工具保留在折叠面板内。原有局部取量与新的全模型可见面扫描是两个操作，不要把局部结果当成全部模型结果。
